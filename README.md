# 📘 國中特教國語文教材自動化製作系統

本儲存庫提供國中特教班國語文教材的自動化製作、語詞圖卡設計與無障礙互動學習網頁工具流。

---

## 🧭 指南與文件導覽

* 🎨 **[語詞圖卡製作指南 (Vocabulary Flashcard Guide)](./語詞圖卡製作指南.md)**
  * 20 個語詞架構規格（12 個常用詞 + 8 個難詞）
  * 特教友善視覺設計風格（手繪塗鴉、純白背景、溫馨粉嫩色）
  * AI 繪圖提示詞 (Prompts) 通用模板與實戰範例庫（支援 ChatGPT / DALL-E 3 / Midjourney / Ideogram / Canva）
  * 跨電腦製作、檔案命名清單與上傳指引

* 📝 **[國文教材製作流程指南 (Chinese Material Builder)](./國文教材製作流程.md)**
  * 從普通班課文生成特教版教材與 `data.json`
  * 利用 NotebookLM 生成手繪風課文簡報
  * 第一階段：自動生成語詞配圖與注釋簡報 PPTX
  * 第二階段：Word 講義與學習單自動排版、動態表格縮放與重組

* 🌐 **[互動學習網頁製作指南 (Interactive Web Guide)](./互動網頁製作流程.md)**
  * 免伺服器、支援離線雙擊即用的特教互動學習網頁製作
  * 語音朗讀、生字詞點讀配對與課文閱讀測驗互動
  * 自動裁切壓縮網頁用圖與部署流程
