# 逐句情境連環漫畫與繪本產生器 (Comic & Storybook Builder)

本技能專為國中特教國文教材打造，將課文逐句分鏡圖文結合微軟 Edge-TTS 真人發音，產出**單一完全獨立自包含的互動網頁（.html）**，並提供**自動部署至 GitHub Pages** 的一條龍流程。

---

在開始製作前，**必須使用 `ask_question` 工具主動向教師提問確認**以下三項需求（切勿自行默認跳過）：


## 核心設計規範（Strict Requirements）

### 1. 頁面純淨度與無干擾規範
- **嚴格禁止在頁面標題、頂部 Banner、卡片標籤或說明中出現任何風格名稱**：
  - ❌ 禁止出現：`（米克師風格）`、`· 色鉛筆手繪風格`、`（水彩風格）`、`點擊此處聽朗讀`。
  - ✅ 正確呈現：直接標示課名與主題，例如：`七下 第六課《今夜看螢去》情境漫畫故事繪本`、卡片僅標示分鏡段落，如 `第一段：荒郊尋螢`。

### 2. 語音生成規範（Edge-TTS）
- **發音人**：微軟繁體中文神經網路女聲 `zh-TW-HsiaoChenNeural`。
- **語速設定**：**嚴格固定為 0.8 倍速**（`rate="-20%"`）。特教學生需要沉穩、咬字分明且溫和的語速以利語音跟讀與詞意理解。
- **播放控制器控制項**：
  - ▶️ **全文朗讀 (Play)**：依序自動連續朗讀所有分鏡，朗讀到的卡片自動高亮放大，繪本模式自動翻頁。
  - ⏸️ **暫停朗讀 (Pause)**：暫停當前語音，保留播放進度。
  - ⏯️ **繼續朗讀 (Resume)**：從暫停處接續播放。
  - ⏹️ **停止朗讀 (Stop)**：停止播放並重置回起點。
  - 🔊 **單格點讀**：點擊各卡片右下角的喇叭按鈕可單獨朗讀該格。

### 3. 單一獨立檔案架構（Self-Contained Single HTML）
- 所有的圖片（16:9 JPEG，品質 82~85）與音訊（MP3）**全部使用 Base64 編碼內嵌**。
- 單檔總體積需控制在 **1.3 MB ~ 1.5 MB** 內，便於學生平板與手機離線或線上快速載入。

### 4. 雙模式介面架構
- **連環漫畫模式（Comic Grid）**：
  - 桌面端與大屏使用 4 欄或 3 欄網格排列，平板與手機使用 2 欄或 1 欄。
  - 卡片呈現完整圖文與段落徽章，點擊卡片放大預覽或點擊喇叭發音。
- **故事繪本模式（Storybook Mode）**：
  - 左右或上下分割版面：左側/上方為超大情境圖，右側/下方為大字體課文（28~32px）與重點高亮。
  - 提供「上一頁」、「下一頁」切換按鈕與鍵盤方向鍵（←/→）支援。

## 🛠️ 自動化建置腳本呼叫

本技能於 `scripts/build_comic_html.py` 提供標準化建置程式。在準備好課文分鏡 JSON 與圖片後，執行：

```bash
uv run --with edge-tts python .agents/skills/comic-story-builder/scripts/build_comic_html.py \
  --data-json "<課次路徑>/comic_data.json" \
  --img-dir "<課次路徑>/圖片" \
  --output "<課次路徑>/<課名>_情境漫畫繪本.html"
```

## 🚀 GitHub 自動提交與 GitHub Pages 部署

HTML 檔案生成後，**必須自動完成以下 Git 提交並提供線上直連網址**：

1. **加入 Git 並提交**：
   ```bash
   git add "<產生的HTML路徑>"
   git commit -m "feat(lesson): 新增<課名>情境漫畫繪本網頁"
   git push origin main
   ```

2. **計算並提供 GitHub Pages 線上網址**：
   - 專案 Pages 根目錄為：`https://ting03040929-cmyk.github.io/special-chinese-lessons/`
   - 對應網址規則：
     `https://ting03040929-cmyk.github.io/special-chinese-lessons/<課次資料夾名>/<HTML檔名>`
   - 提供給使用者時，附上 Markdown 超連結，讓教師一鍵點開測試或提供給學生平板使用。
